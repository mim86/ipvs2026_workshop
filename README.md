# IPVS 2026 HPV16 bioinformatics workshop

This hands-on workshop uses simulated HPV16 sequencing reads to explore read quality, mapping, genome coverage, consensus sequences, and variant calling against A1 and B1 references. No patient data are included.

To get the workshop files, click **Code → Download ZIP** above and extract the downloaded archive. Then open `hpv_workshop_snakemake/Instructions_and_tasks.docx` and follow the setup and exercise instructions for your operating system. Keep the `.fastq.gz` files compressed; the instructions use a Docker image containing the required analysis tools.
